# Landing page: парикмахер и массажист Айгуль Саяхова

Готовый одностраничный сайт. Нет бэкенда и нет шагов сборки — достаточно открыть `index.html` в браузере.

## Структура файлов

```
index.html
css/style.css
js/main.js
README.md
.nojekyll
```

## Стек (без Next.js)

Среда не поддерживает Node.js/npm, поэтому сайт сделан на чистом **HTML5 + CSS + vanilla JS**.
- Шрифты: Playfair Display (заголовки), Inter (текст) — подключаются через Google Fonts.
- Изображения: временные URL с Unsplash (`loading="lazy"`).
- Анимации: `IntersectionObserver`, учитывается `prefers-reduced-motion`.
- Валидация формы на клиенте, сохранение заявок в `localStorage`.
- Отправка заявки через WhatsApp (вариант Б).

## Запуск

1. Откройте папку с файлом `index.html`.
2. Откройте `index.html` в любом современном браузере (Chrome, Firefox, Edge, Safari).
3. Для проверки на локальном сервере можно использовать любую утилиту, например Live Server в VS Code или Python:
   - `python -m http.server 8000` → http://localhost:8000

Сборка не требуется.

## Деплой на GitHub Pages

1. Создать репозиторий на GitHub.
2. `git init && git add . && git commit -m "initial"`
3. `git remote add origin <URL>`
4. `git push -u origin main`
5. Settings → Pages → Source: Deploy from branch → main → / (root) → Save.
6. Сайт будет доступен по адресу https://USERNAME.github.io/REPO/
7. После деплоя заменить `https://USERNAME.github.io/REPO/` в `index.html` на реальный URL.

Файл `.nojekyll` уже создан в корне для отключения Jekyll на GitHub Pages.

## Форма записи и интеграция

Форма работает по варианту Б (отправка в мессенджер):
1. Валидирует имя, телефон, услугу и дату.
2. При успехе сохраняет заявку в `localStorage` под ключом `salon_bookings`.
3. Открывает WhatsApp с готовым текстом заявки.
4. Показывает блок успеха со ссылкой на WhatsApp.

Кнопки «Написать в WhatsApp» и «Написать в MAX» добавлены под формой и в секции контактов.

## Доступность и адаптив

- Семантическая верстка (`header`, `nav`, `main`, `section`, `footer`).
- Skip-ссылка для клавиатурной навигации.
- Адаптив от 320 px: одна колонка на телефонах, 2–4 колонки на десктопах.
- Burger-меню на мобильных устройствах.
- Все кнопки «Записаться» прокручивают страницу к форме (`#booking`).
- `prefers-reduced-motion` отключает анимации.
